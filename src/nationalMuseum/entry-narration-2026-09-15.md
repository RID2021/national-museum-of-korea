# 첫 입장 나레이션

- 외부맵(밤) `R57laZ` 최초 입장 시 기존 2쪽 프롤로그 나레이션을 자동 표시한다.
- `museumJourney.prologueSeen`을 플레이어 저장소에 보존하여 재접속·재방문 시 반복하지 않는다. 기존 스토리/미션 진행 기록이 있는 플레이어도 건너뛴다.
- 나레이션 완료/닫기는 NPC 대화나 맵 이동을 자동 실행하지 않는다. 직접 입구를 통과해 반가사유상 가까이 가서 F를 누르면 본 대화가 시작된다.
- 일반 전시실 자동 대화 없음, 미션 성공 후 조건부 이동, 엔딩 흐름은 유지한다.
- 회귀 테스트 33개, TypeScript 검사, 배포 빌드 통과. CLI 게시 후 실제 맵이 이전 버전을 표시하여 관리자 웹에서 같은 ZIP을 앱 `53Xe2L`에 직접 업로드·수정 완료했다.
- 실제 검증에서 기존 완료 플레이어의 진행 기록은 초기화하지 않는다. 최초 입장·중복 방지·완료 후 비이동은 자동 테스트로 검증했다.
