## 동작

임시 `museum-hud-v1.html` 파일과 표시 코드를 제거했다. 기존 진행률 열기 버튼은 박물관 스페이스에서 새 어댑터 `src/nationalMuseum/progress.ts`를 사용한다. 기존 고분 데이터와 박물관 데이터가 섞이지 않게 위젯 참조도 분리했다.

| 조건 | 편의 이동 |
| --- | --- |
| 안내 대화 미완료 | 잠금 |
| 안내 대화 마지막 페이지 완료 | 해당 대화에서 해제한 다음 장소로 이동 가능 |
| 미션만 성공하고 성공 대화 미완료 | 잠금, 성공 대화를 끝까지 읽도록 안내 |
| 미션 및 성공 대화 완료 | 다음 미완료 미션의 전시실로 이동 가능 |
| 이미 다음 미션 전시실 안 | 그 전시실 체험을 안내, 다음 미션 건너뛰기 금지 |
| 대화/게임 위젯 진행 중 | 이동 금지 |
| 7개 미션 완료 | 외부 낮 맵 이동 가능, 이미 낮 맵이면 완료 표시 |

기존 성공 대화 완료 시 자동 맵 이동은 삭제하지 않았다. 이번 버튼은 그 후 로비 등에서 다음 전시실로 가는 편의를 제공한다. 목적지 진입 시 NPC/게임 자동 실행은 복원하지 않았다.
