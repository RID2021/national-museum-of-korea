## 에디터 필드

오브젝트의 유형은 `ZEP Script 상호작용`입니다. 이름에는 NPC 이름, `값(선택 사항)`에는 위 표의 문자열을 넣었습니다. `번호`는 사유상 ①이 1, ②가 2이며 다른 맵의 해당 NPC는 기본값 1입니다. 실행 방법은 `F키를 눌러 실행`입니다. 반가사유상의 실행 범위는 0, 나머지 유물은 기존 기본값 1을 유지했습니다.

로봇은 두 오브젝트 레이어에서 직접 선택되지 않고 배경에 포함되어 있어, 로봇 발밑 바로 앞의 통행 가능한 바닥에 지정 영역을 추가했습니다. 통과 불가 타일과 겹치지 않는 3×2칸 영역을 에디터에서 확인했습니다. 영역 이름은 `npc:안내로봇`이며 영역 진입/접촉을 기존 대화 엔진이 처리합니다. 텍스트 오브젝트는 배치하지 않았습니다.

## 검증과 남은 확인

- 확인: 모든 표의 트리거 입력값, 오브젝트/영역 저장 완료 메시지, 각 맵의 박물관 노말 앱 선택 및 저장.
- 확인: 사유의 방 실제 플레이에서 `#npc 반가사유상1`로 1/7 대화창이 열렸습니다.
- 확인: 신라실(2) 실제 플레이에서 `#npc museum-jinheung-stele`로 순수비 프로필과 1/4 첫 대사가 표시됐습니다. 위젯 URL의 앱 ID도 `53Xe2L`입니다.
- 미확인: 모든 오브젝트의 실제 F 상호작용 및 로봇 영역 진입. 조작 도구의 짧은 키 입력으로 이동이 불안정해 전체 동선 검수를 완료하지 못했습니다. 실행 범위가 관람 동선에 충분한지도 실플레이에서 확인해야 합니다.
- 미해결: 앱 시작 시 `설치된 앱에서 에러가 감지되었습니다` 알림이 관찰됐습니다. `!scriptlog`로 로그 표시를 활성화했으나 상세 예외는 확인되지 않았습니다. 위 관리자 대화 명령은 실행됩니다. 이 기록은 무오류 검증 완료를 의미하지 않습니다.
