# 벽돌 게임 이미지 적용

- 게임 소스: res/html/museum-game.template.html. build-museum-widget.cjs가 museum-game-v1.html을 생성합니다.
- 무늬 이름을 키로 이미지를 선택하므로 저장된 배열과 자리 교환에 함께 대응합니다.
- PC 4열 / 모바일 2열, 스크롤 가능한 본문과 고정 확인 버튼. 이름과 선택 상태를 유지합니다.
- 원본 8종은 output, 게임용 256px 투명 PNG는 res/images/baekje-bricks에 있습니다.
- 이미지 중복과 템플릿은 배포 압축에서 제외합니다. 압축 16,701,157 bytes로 16 MiB 제한 이내지만 남은 용량이 적습니다.
- 자동 테스트 37개, 빌드 성공. 로컬 Chromium 1100×820 및 360×640 화면 확인, 이미지 8/8 로드, 가로 넘침 없음, 실제 클릭의 pick 메시지 및 선택 표시 확인.
- ZEP 실서버에서의 플레이 검증 및 물리적 모바일 기기 터치 검증과는 별개입니다.
